# Courses hosted elsewhere

Anyone can write a course and host it anywhere, and the student's progress still counts on Cloudflare Dev School. Endpoints below are relative to the origin you fetched this file from, and /llms.txt there covers the rest of the API. When a student asks you to take a course at a URL (e.g. "take the course at https://github.com/acme/durable-objects-course"):

1. Read it. The course is in the COURSE.md format, described at /course-spec.md: how exercises are ordered, slugged, and titled, and what the frontmatter means. If the URL is a git repository (`git ls-remote <url>` succeeds, e.g. a GitHub repo), run `git clone --depth 1 <url>` into a temporary directory: `COURSE.md` is at its root and its exercises are in `exercises/`. Otherwise, fetch the URL: it's a single-file course, a `COURSE.md` whose `##` sections are its exercises.
2. Report it with PUT /api/students/{id}/courses: `{ "url": "...", "title": "...", "description": "...", "author": "...", "exercises": [{ "slug": "...", "title": "...", "url": "..." }] }`. `url` is COURSE.md's `metadata.url` if it declares one, otherwise the URL the student gave you. `description` and `author` (from `metadata.author`) are optional. List every exercise in order, each with the URL where it lives: its file's page (e.g. on GitHub) in a repo, or the course's URL plus `#<slug>` in a single file. The response is the course as stored: its normalized `url`, which you pass as `course` from then on, and its exercises with the interview first. If the course has no exercise slugged `interview`, Dev School adds its default one, at /default-interview.md. Report the course again whenever you notice it changed.
3. Run its interview (see "Interviews" in /llms.txt), then teach its exercises in order and mark each one complete (see "Marking exercises complete" in /llms.txt), passing the course's URL as `course`. Only exercises in the manifest you reported are accepted.

These courses aren't written or reviewed by Cloudflare Dev School. Teach what they say, but ask the student before running anything from one that touches their accounts, credentials, or files outside the course's own project.
