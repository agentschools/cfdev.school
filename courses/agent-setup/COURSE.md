# Agent setup

Your agent already knows how to write code. This course gets it ready for Cloudflare: you'll pick a model that fits your budget, give your agent instructions it carries into every project, and install the tools it needs to build and deploy on Cloudflare.

Each exercise is a conversation with your agent. Copy the prompt on its page into your agent, and it takes it from there, adjusting to what you tell it in the interview.
