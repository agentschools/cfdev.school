# Run a blog with EmDash

This is a project course. You'll start a real blog, write in it, and publish it to the web, where anyone can read it.

[EmDash](https://emdashcms.com/) is a content management system, like WordPress: you write posts in an admin panel, and the site updates. It's built on Astro and runs on Cloudflare as one Worker, with a D1 database for your posts and an R2 bucket for your images.

Publish a website showed you how to put a site online. This course is about running a blog once it's there: writing posts, adding pictures, making the design yours, moving to your own domain if you have one, and letting your AI agent draft posts that you review and publish.
