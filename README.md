# Cloudflare Dev School

Cloudflare Dev School is an open-source project that teaches people how to build on Cloudflare using whatever AI-powered coding agent they already have installed, like Claude Code, OpenAI Codex, OpenCode, Pi, Cursor, etc.

Check it out at [cfdev.school](https://cfdev.school)

See [`AGENTS.md`](./AGENTS.md) for the stack, scripts, and conventions. Plans and decisions live in GitHub issues.

## Community conduct

See the proposed [Contributor Covenant code of conduct](./CODE_OF_CONDUCT.md).
The draft uses a maintainer-supplied temporary private reporting contact while
enforcement coverage is finalized. Please do not post confidential reports in
public issues or PRs.
